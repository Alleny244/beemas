# Beemas Salon Website

A premium, 3D modern website for Beemas Makeover Studio.

## How to Run

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Open in Browser**:
   Navigate to [http://localhost:5173/](http://localhost:5173/)

## Technologies Used
- **Vite** & **React**
- **Spline** (3D Integration)
- **Lucide React** (Icons)
- **Framer Motion** (Animations)
- **Vanilla CSS** (Design System)
